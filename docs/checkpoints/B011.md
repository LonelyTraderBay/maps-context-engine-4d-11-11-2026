## Dựng lại từ checkpoint

Khôi phục source trong clone sạch từ verified bundle và kiểm commit/tree/tag. Vật liệu build gồm Go 1.27.4, Node 24.22.3, TypeScript 5.9.3, CPython 3.14.4 và Chromium 159.0.8154.6 cùng các pin/caches B010. Các bước offline của B010 gồm `go mod verify`, `go test -count=1 ./...`, `go vet ./...`, `go run ./tools/spec_check`, lint/typecheck/test/build Explorer và hai build CLI, gồm build có Explorer assets nhúng. `version --json` kiểm từng binary. Dùng assets mới dựng cho browser test. Native protected owner dùng test suite `internal/store/sqlite` và state-profile đã compile, với chroot chỉ có scope synthetic. Kiểm C078 lại theo `tools/bench/README.md` và C079 theo `packages/powershell-provider/README.md` với SHA-256 đã pin.

S21 giữ locator và hash cho evidence ngoài Git, gồm metrics thực nghiệm và phạm vi test. `artifacts/preflight/b011-checkpoint/` giữ combined/restore receipt và verified bundle. Bundle giữ source, tests và các fixture tự tạo. Dữ liệu runtime SQLite, toolchains bên ngoài và dữ liệu dự án đích có vòng đời lưu trữ riêng. Real-repo nghiệm thu rộng, user-level editor integration và host token savings chưa có nhãn phát hành tương ứng.
