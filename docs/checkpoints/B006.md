## Dựng lại trên Linux amd64

Dùng workspace riêng từ commit và các tag đã xác minh. Dùng Go 1.27.4, Node 24.22.3, module cache đã xác minh và npm cache tương ứng package-lock. T043 pin compiler TypeScript 5.9.3, archive, manifest của từng tệp và executable Node trong `packages/ts-provider/toolchain-pin.json`. Cấp vật liệu compiler đã duyệt và Node qua biến test `MCE4D_T044_COMPILER` và `MCE4D_T055_NODE` như biên bản E879–E881. Cài dependency của chính workspace bằng `npm ci --offline --ignore-scripts --no-audit --no-fund --engine-strict`. Chỉ dùng fixture synthetic và namespace mạng loopback.

Chạy `npm run lint -w @mce4d/explorer`, `npm run typecheck -w @mce4d/explorer`, `npm test -w @mce4d/explorer`, `npm run build -w @mce4d/explorer` và `node --test tests/acceptance/explorer_selection.test.mjs`. Chạy `go mod verify`, `go test -count=1 ./...`, `go vet ./...` và `go run ./tools/spec_check` theo runner S51. Build `./cmd/mce4d`, cùng bản embed có tag `mce4d_explorer_assets` với asset vừa dựng ở `cmd/mce4d/explorer_dist`. Workspace restore giữ config, SQLite và runtime state riêng.
