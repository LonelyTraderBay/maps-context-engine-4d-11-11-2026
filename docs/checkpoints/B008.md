# B008 — Flow tĩnh và hợp đồng backend

B008 gồm T093, T094, T046, T059, T060, T061, T095, T096, T097 và T098 theo S47. Phạm vi gồm lựa chọn Explorer sang context pack, nghiệm thu Preview GU1, catalog nhóm, MySQL source, OpenAPI/JSON Schema/Proto3, event/cache, ghép hợp đồng theo scope và flow Go cùng nhóm giao dịch tĩnh.

Dựng lại với Go, Node, npm cache và Chromium đã xác minh theo hồ sơ preflight. Chạy npm offline với `--ignore-scripts`, kiểm contract/spec, Go test/vet/build/race, frontend lint/typecheck/test/build, SDK browser fixture, hash core và Explorer. Explorer Linux dùng các tag `mce4d_ui_maps,mce4d_explorer_assets` và SQLite V4. Các phép thử Browser dùng repository fixture do dự án tạo. SQL, event và kết quả lưu chỉ phản ánh bằng chứng tĩnh đã capture.

Cấu hình SQL tùy chọn nằm trong file capture `mce4d-flow.json` với `schema_version` bằng 1, `sql_profile` theo T059 và `schema_paths` là danh sách đường dẫn SQL cùng phạm vi. Ví dụ cấu hình fixture nằm trong `tests/acceptance/explorer_flow.py`. Bộ nạp Go cần profile typed và toolchain được phê duyệt. Event binding dùng kết quả adapter T061 từ owner đã kiểm chứng.

Biên nhận kiểm từng task nằm ở S21. Danh mục staged, build, restore và SHA-256 của bundle nằm trong `artifacts/preflight/t098-20261121/`. Annotated tag `mce4d/checkpoints/B008` ghi commit, tree và hash biên nhận khi restore đạt. GU2 còn phụ thuộc T099 và T100.
